# Contact List Manager

## Overview

This project is a simple web application developed using HTML, CSS, and JavaScript. The application demonstrates the use of JSON data for storing and managing contact information. Users can view existing contacts, add new contacts, and remove contacts from the list.

## Features

* Display contacts in an HTML table
* Add new contacts through a form
* Remove contacts by name
* Validate user input before adding contacts
* Dynamic table updates without reloading the page

## Technologies Used

* HTML5
* CSS3
* JavaScript
* JSON
